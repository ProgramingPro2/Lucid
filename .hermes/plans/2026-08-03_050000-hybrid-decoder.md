# Hybrid Decoder (JEPA Reasoner + Fluent Writer) Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Replace the weak reconstruction-only `TextDecoder` with a GPT-2-scale "fluent writer" that first learns to write natural language (next-token on a large corpus) and then learns to be *aimed* by the JEPA's predicted concept vector. This targets the real bottleneck — the current pipeline *reconstructs* rather than *writes* — and is the path toward GPT-2-comparable output.

**Architecture:** Keep the JEPA encoder + predictor (the "reasoner" that decides what to say next in meaning-vector space). Swap the small 6-layer/512-dim `TextDecoder` for a ~12-layer/768-dim autoregressive transformer (~124M params, GPT-2-small scale) that is trained **in two phases**:
1. **Phase 1 — fluent writer**: pretrain it as a plain next-token LM on a large corpus (it learns word-level fluency from billions of token statistics).
2. **Phase 2 — conditioning**: freeze or fine-tune it to take a concept vector (the JEPA's decision) + the text-so-far and generate the continuation. This is the JEPA-Reasoner pattern (decouple reasoning from token-writing).

**Tech Stack:** PyTorch 2.6, existing Lucid codebase at `~/Documents/Lucid/`, GPT-2 tokenizer (already in the project), RTX 3090 24GB.

## Architecture Overview

```
                    ┌─────────────────────────────────────────────┐
                    │           REASONER (JEPA, frozen)           │
                    │  encoder(prompt) → predictor → next-vector  │
                    └──────────────────────┬──────────────────────┘
                                           │ z (512-dim) = "what to say next"
                                           ▼
                    ┌─────────────────────────────────────────────┐
                    │            WRITER (autoregressive)          │
                    │  GPT2-transformer, 12L/768d, ~124M params   │
                    │  input = [z-conditioning prefix] + text-so-far│
                    │  output = next token (word by word)          │
                    └─────────────────────────────────────────────┘
```

Phase 1 makes the writer fluent. Phase 2 makes it obey the concept vector. Two separate training objectives, two separate stages, one shared tokenizer.

## Task 1: Create the `FluWriter` model (`src/conceptpoc/jepa/writer.py`)

**Objective:** A GPT-2-scale autoregressive decoder that can be (a) pretrained as a plain next-token LM and (b) conditioned on a concept vector. Use modern best practices: RoPE (rotary positional encoding), RMSNorm, SwiGLU feed-forward, no absolute positional embeddings, weight-tying optional.

**Files:**

**Step 1: Write the model**

```python
"""GPT-2-scale fluent writer decoder, optionally conditioned on a concept vector.

Phase 1: plain next-token LM (self.gradient of language).
Phase 2: conditioned on a 512-dim concept vector (the JEPA reasoner's decision)
so the writer can be "aimed" at the intended next sentence.

Modern best practices: RoPE rotary positions, RMSNorm, SwiGLU FFN.
"""
from __future__ import annotations

import math
import torch
import torch.nn.functional as F
from torch import nn


def rms_norm(x: torch.Tensor, w: torch.Tensor, eps: float = 1e-5) -> torch.Tensor:
    return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + eps) * w


class RMSNorm(nn.Module):
    def __init__(self, dim: int, eps: float = 1e-5) -> None:
        super().__init__()
        self.w = nn.Parameter(torch.ones(dim))
        self.eps = eps

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return rms_norm(x, self.w, self.eps)


def precompute_rope(seq_len: int, dim: int, base: float = 10000.0, device="cpu") -> torch.Tensor:
    inv_freq = 1.0 / (base ** (torch.arange(0, dim, 2, dtype=torch.float32, device=device) / dim))
    t = torch.arange(seq_len, dtype=torch.float32, device=device)
    freqs = torch.outer(t, inv_freq)  # (seq, dim/2)
    return torch.cat([freqs, freqs], dim=-1)  # (seq, dim)


def apply_rope(x: torch.Tensor, cos: torch.Tensor, sin: torch.Tensor) -> torch.Tensor:
    """x: (B, T, H, D)}, cos/sin: (T, D)."""
    d = x.shape[-1]
    x1 = x[..., : d // 2]
    x2 = x[..., d // 2 :]
    return torch.cat([x1 * cos - x2 * sin, x2 * cos + x1 * sin], dim=-1)


class SwiGLU(nn.Module):
    def __init__(self, dim: int, hidden: int) -> None:
        super().__init__()
        self.w_gate = nn.Linear(dim, hidden, bias=False)
        self.w_up = nn.Linear(dim, hidden, bias=False)
        self.w_down = nn.Linear(hidden, dim, bias=False)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.w_down(F.silu(self.w_gate(x)) * self.w_up(x))


class SelfAttention(nn.Module):
    def __init__(self, dim: int, n_heads: int, rope_len: int, dropout: float = 0.0) -> None:
        super().__init__()
        self.n_heads = n_heads
        self.head_dim = dim // n_heads
        self.qkv = nn.Linear(dim, 3 * dim, bias=False)
        self.out = nn.Linear(dim, dim, bias=False)
        self.norm = RMSNorm(dim)
        self.register_buffer("cos", torch.cos(precompute_rope(rope_len, dim)).unsqueeze(0).unsqueeze(0))
        self.register_buffer("sin", torch.sin(precompute_rope(rope_len, dim)).unsqueeze(0).unsqueeze(0))
        self.drop = nn.Dropout(dropout) if dropout > 0 else nn.Identity()

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        b, t, _ = x.shape
        h = self.norm(x)
        qkv = self.qkv(h).reshape(b, t, 3, self.n_heads, self.head_dim).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]
        q = apply_rope(q, self.cos[:, :, :t], self.sin[:, :, :t])
        k = apply_rope(k, self.cos[:, :, :t], self.sin[:, :, :t])
        attn = (q @ k.transpose(-2, -1)) / math.sqrt(self.head_dim)
        causal = torch.triu(
            torch.full((t, t), float("-inf"), device=x.device), diagonal=1
        )
        attn = attn + causal
        attn = F.softmax(attn, dim=-1)
        out = self.drop(attn) @ v
        out = out.transpose(1, 2).reshape(b, t, -1)
        return self.out(out)


class Block(nn.Module):
    def __init__(self, dim: int, n_heads: int, rope_len: int, ff_mult: int = 4, dropout: float = 0.0) -> None:
        super().__init__()
        self.attn = SelfAttention(dim, n_heads, rope_len, dropout)
        self.ffn = nn.Sequential()
        hidden = dim * ff_mult
        self.ffn = SwiGLU(dim, hidden)
        self.norm2 = RMSNorm(dim)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = x + self.attn(x)
        x = x + self.ffn(self.norm2(x))
        return x


class FluWriter(nn.Module):
    """Autoregressive writer head. Optional concept conditioning (Phase 2)."""

    def __init__(
        self,
        vocab_size: int,
        dim: int = 768,
        n_layers: int = 12,
        n_heads: int = 12,
        ff_mult: int = 4,
        max_seq_len: int = 256,
        concept_dim: int = 512,
        use_concept: bool = True,
        dropout: float = 0.0,
    ) -> None:
        super().__init__()
        self.vocab_size = vocab_size
        self.dim = dim
        self.use_concept = use_concept
        self.tok_embed = nn.Embedding(vocab_size, dim)
        self.blocks = nn.ModuleList(
            [Block(dim, n_heads, max_seq_len + 8, ff_mult, dropout) for _ in range(n_layers)]
        )
        self.norm_out = RMSNorm(dim)
        self.lm_head = nn.Linear(dim, vocab_size, bias=False)
        # Tie input embedding and output head (weight tying) to save params and
        # improve fluency.
        self.tok_embed.weight = self.lm_head.weight
        if use_concept:
            self.concept_proj = nn.Linear(concept_dim, dim, bias=False)

    def forward(
        self,
        input_ids: torch.Tensor,
        concept: torch.Tensor | None = None,
        labels: torch.Tensor | None = None,
    ) -> torch.Tensor:
        """input_ids: (B, T); concept: (B, concept_dim) optional."""
        b, t = input_ids.shape
        h = self.tok_embed(input_ids)
        if self.use_concept and concept is not None:
            # Prepend a learned concept token: (B, 1, dim), attend-over-all.
            c = self.concept_proj(concept).unsqueeze(1)  # (B, 1, dim)
            h = torch.cat([c, h], dim=1)  # (B, T+1, dim)
        else:
            # No concept: still need a start token so positions line up.
            start = torch.zeros(b, 1, self.dim, device=input_ids.device)
            h = torch.cat([start, h], dim=1)
        for blk in self.blocks:
            h = blk(h)
        h = self.norm_out(h)
        # Remove the concept/start token before the LM head.
        logits = self.lm_head(h[:, 1:])  # (B, T, vocab)
        if labels is not None:
            loss = F.cross_entropy(
                logits.reshape(-1, self.vocab_size),
                labels.reshape(-1),
                ignore_index=-100,
            )
            return loss
        return logits

    @torch.no_grad()
    def generate(
        self,
        pos_ids: torch.Tensor,
        concept: torch.Tensor,
        max_tokens: int,
        temperature: float = 0.8,
        top_k: int = 50,
        eos_id: int = None,
        bos_id: int = None,
    ) -> torch.Tensor:
        """Greedy/temperature-sample from a concept vector (no prior text)."""
        self.eval()
        generated = torch.full((pos_ids.size(0), 1), bos_id, dtype=torch.long, device=pos_ids.device)
        for _ in range(max_tokens):
            logits = self.forward(generated, concept)
            logits = logits[:, -1, :] / max(temperature, 1e-6)
            # top-k
            if top_k > 0:
                kth = logits.topk(min(top_k, logits.size(-1))).values[:, -1:]
                logits = logits.masked_fill(logits < kth, float("-inf"))
            probs = F.softmax(logits, dim=-1)
            nxt = torch.multinomial(probs, 1)
            generated = torch.cat([generated, nxt], dim=1)
            if eos_id is not None and (nxt == eos_id).all():
                break
        return generated

    def num_parameters(self) -> int:
        return sum(p.numel() for p in self.parameters())
```

```python
"""Token-window streaming for writer pretraining (Phase 1)."""
from __future__ import annotations

import torch
from torch.utils.data import DataLoader, Dataset, IterableDataset
from ..data.corpus import load_documents
from ..jepa.tokenizer import Tokenizer


class TokenWindowIterable(IterableDataset):
    def __init__(self, docs, tokenizer: Tokenizer, seq_len: int = 256) -> None:
        self.docs = docs
        self.tok = tokenizer
        self.seq_len = seq_len

    def __iter__(self):
        buf: list[int] = []
        for doc in self.docs:
            for sent in doc.sentences:
                ids, _ = self.tok.encode_batch([sent], 128)
                buf.extend(ids[0].tolist())
                buf.append(self.tok.eos_id)
                while len(buf) >= self.seq_len:
                    chunk = buf[: self.seq_len]
                    x = torch.tensor(chunk[:-1], dtype=torch.long)
                    y = torch.tensor(chunk[1:], dtype=torch.long)
                    yield x, y
                    buf = buf[self.seq_len - 1 :]
        # flush remainder
        if len(buf) >= 2:
            x = torch.tensor(buf[:-1], dtype=torch.long)
            y = torch.tensor(buf[1:], dtype=torch.long)
            yield x, y


def make_phase1_loader(corpus_path, tokenizer: Tokenizer, seq_len: int, batch_size: int):
    docs = load_documents(corpus_path)
    ds = TokenWindowIterable(docs, tokenizer, seq_len)
    return DataLoader(ds, batch_size=batch_size)
```

```python
"""Phase-1: pretrain FluWriter as a plain next-token LM (fluency)."""
from __future__ import annotations

import torch
from torch.utils.data import DataLoader
from ..config import Config
from ..jepa.tokenizer import Tokenizer
from ..jepa.writer import FluWriter
from .data import make_phase1_loader
from ..ckpt_db import CheckpointDB
from ..progress import iter_bar, log_epoch


def train_phase1(cfg: Config, progress: bool = True) -> tuple[FluWriter, Tokenizer]:
    torch.manual_seed(cfg.jepa.seed)
    tok = Tokenizer(cfg.jepa.tokenizer)
    seq_len = cfg.writer.seq_len
    loader = make_phase1_loader(cfg.data.corpus_path, tok, seq_len, cfg.writer.batch_size)

    model = FluWriter(
        tok.vocab_size,
        dim=cfg.writer.dim,
        n_layers=cfg.writer.n_layers,
        n_heads=cfg.writer.n_heads,
        max_seq_len=seq_len + 8,
        concept_dim=cfg.jepa.dim,
        use_concept=False,  # Phase 1: no conditioning
    )
    dev = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model.to(dev)
    opt = torch.optim.AdamW(model.parameters(), lr=cfg.writer.lr, weight_decay=0.01)
    steps_per_epoch = max(1, cfg.writer.steps_per_epoch)

    db = None
    start_epoch = 0
    if cfg.writer.db_path:
        db = CheckpointDB(cfg.writer.db_path)
        loaded = db.load_latest_checkpoint(cfg.writer.run_id, dev) if cfg.writer.run_id else None
        if loaded is not None:
            model.load_state_dict(loaded[0]); opt.load_state_dict(loaded[1]); start_epoch = loaded[2] + 1

    import itertools
    for epoch in range(start_epoch, cfg.writer.epochs):
        model.train()
        total_loss = 0.0; n = 0
        it = iter(loader)
        for _ in iter_bar(range(steps_per_epoch), desc=f"writer epoch {epoch+1}/{cfg.writer.epochs}", enabled=progress):
            # Iterate streaming data; skip when exhausted (new epoch resamples the DS)
            try:
                x, y = next(it)
            except StopIteration:
                it = iter(loader); x, y = next(it)
            x, y = x.to(dev), y.to(dev)
            opt.zero_grad()
            loss = model(x, labels=y)
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            opt.step()
            total_loss += loss.item(); n += 1
        avg = total_loss / max(1, n)
        log_epoch("writer-p1", epoch+1, cfg.writer.epochs, {"loss": avg}, enabled=progress)
        if db is not None:
            db.record_epoch(cfg.writer.run_id, epoch, {"loss": avg})
            db.save_checkpoint(cfg.writer.run_id, epoch, model, opt)
    if db: db.close()
    return model, tok
```

```python
    path = Path(path); path.parent.mkdir(parents=True, exist_ok=True)
    torch.save({"state_dict": model.state_dict(), "config": config}, path)

def load_writer(path, config: dict):
    from .jepa.writer import FluWriter
    blob = torch.load(Path(path), map_location="cpu", weights_only=False)
    m = FluWriter(**config)
    m.load_state_dict(blob["state_dict"])
    m.eval()
    return m
```

## Verification / acceptance criteria

- Phase-1 pretrained writer produces fluent, grammatical sentences (loss plausibly low, no collapse/vocab collapse).
- Phase-2 writer obeys the concept vector: same prompt + different concept → different, concept-appropriate text; text is fluent.
- End-to-end `generate-hybrid` tracks the prompt's topic better than the old recon path (judge score > ~0.1 on the eval harness, up from ~0.002).
- No CUDA OOM; checkpoints resume correctly on interruption.

## Risks & tradeoffs

| Risk | Mitigation |
|------|-----------|
| Phase-2 catastrophically forgets fluency | Freeze base layers; only train concept_proj + top ~3 layers; low lr |
| Weight tying + SwiGLU changes semantics | Sanity-test against old decoder output |
| 124M writer too big alongside Lemonade | GPU gate + per-epoch DB checkpoints; resume loses ≤1 epoch |
| Concept vector isn't a strong enough aim signal | Increase concept strength (scale), train concept_proj with higher lr, or add FiLM-style injection into every block |
| Phase-1 needs a big corpus for real fluency | Start on `corpus_1m` (24M words) for proof; scale to a larger public corpus (FineWeb sample) later |

## Open questions

- Should the writer be fully unfrozen in Phase 2 (full conditioning) or keep a frozen fluent base (safer)? Plan starts with **frozen base + tunable top**, easy to relax.
- Which corpus for Phase-1? `corpus_1m` now (fast proof), FineWeb-10B later (real fluency).
